Comment ça marche
  • Montage : glisse un symbole de la palette jusqu'à une case (ou choisis-le, puis clique dans les cases). Glisse un symbole déjà placé pour le déplacer; sur une case occupée, les deux s'échangent. Ctrl + glisser fait une copie.
  • Avec l'outil Fil, glisse pour tracer plusieurs fils d'un coup.
  • Clique sur le titre d'un circuit pour changer son nom et les repères des rails. Clique à droite d'une ligne pour la nommer.
  • ⚡ Circuit de puissance ajoute une section séparée (L1/L2) en haut : ses contacts suivent les bobines du circuit de commande qui portent le même repère.
  • Branche parallèle : clique entre deux rangées, vis-à-vis d'une jonction, pour ajouter ou enlever un lien vertical.
  • Un contact suit la bobine qui porte le même repère (ex. CR1, M, TR1). Les numéros sous une bobine indiquent où sont ses contacts (souligné = NF).
  • Simulation : appuie sur les boutons directement dans le schéma ou dans le panneau. Maj + clic (ou un appui long sur écran tactile) garde un bouton-poussoir enfoncé; touche-le de nouveau pour le relâcher.
  • Installer l'app : sur Android (Chrome), bouton 📲 Installer ou menu ⋮ → Installer l'application. Sur iPhone/iPad (Safari), bouton Partager → Sur l'écran d'accueil. Elle fonctionne ensuite sans Internet.
  • Clic droit ou Suppr pour effacer, Ctrl+Z pour annuler. Ton schéma est gardé dans ce navigateur.
