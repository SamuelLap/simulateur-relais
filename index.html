Comment ça marche
  • Montage : glisse un symbole de la palette jusqu'à une case (ou choisis-le, puis clique dans les cases). Glisse un symbole déjà placé pour le déplacer; sur une case occupée, les deux s'échangent. Ctrl + glisser fait une copie.
  • Avec l'outil Fil, glisse pour tracer plusieurs fils d'un coup.
  • Onglets : Relais, Électronique, Moteur monophasé, Moteur triphasé, Automate. Chaque onglet garde son propre schéma.
  • Mesures : place un voltmètre (Maj+V) en parallèle, un ampèremètre (Maj+A) en série, ou une sonde d'oscilloscope (Maj+S). Les valeurs s'affichent sur le schéma et dans le panneau. La puissance des charges se règle dans leurs propriétés.
  • Triphasé : le circuit de puissance est vertical (L1 L2 L3). Le contacteur 3 pôles suit la bobine du même repère. L'outil Pont relie deux conducteurs (glisse d'un point à l'autre) pour croiser les phases. En simulation, clique un fusible pour le griller et voir une perte de phase.
  • Automate : les entrées (I0.x) s'allument quand elles reçoivent la tension; les sorties (Q0.x) se forcent dans le panneau ou recopient les entrées.
  • Sélectionner : clique un symbole, ou glisse pour encadrer une zone; Maj+clic ajoute à la sélection. Déplacer (D) : glisse un symbole ou toute la sélection (Ctrl pour copier); dans le vide, il déplace la vue.
  • Raccourcis clavier (ordinateur) : appuie sur ? pour la liste. Ex. R relais, M moteur, C contact NO, Maj+C contact NF, L fil, Tab pour passer en simulation, 1 à 9 pour actionner les boutons.
  • Se déplacer et zoomer : glisse dans une zone vide du schéma pour le déplacer. Sur écran tactile, pince avec deux doigts pour zoomer. À l'ordinateur, Ctrl + molette. Les boutons − / Ajuster / + font la même chose.
  • Le menu ☰ regroupe les exemples, le circuit de puissance, la taille de la grille, l'export et l'import. Les boutons 🧰 et 🎛️ cachent la palette et le panneau pour donner plus de place au schéma.
  • Clique sur le titre d'un circuit pour changer son nom et les repères des rails. Clique à droite d'une ligne pour la nommer.
  • ⚡ Circuit de puissance ajoute une section séparée (L1/L2) en haut : ses contacts suivent les bobines du circuit de commande qui portent le même repère.
  • Branche parallèle : clique entre deux rangées, vis-à-vis d'une jonction, pour ajouter ou enlever un lien vertical.
  • Un contact suit la bobine qui porte le même repère (ex. CR1, M, TR1). Les numéros sous une bobine indiquent où sont ses contacts (souligné = NF).
  • Simulation : appuie sur les boutons directement dans le schéma ou dans le panneau. Maj + clic (ou un appui long sur écran tactile) garde un bouton-poussoir enfoncé; touche-le de nouveau pour le relâcher.
  • Installer l'app : sur Android (Chrome), bouton 📲 Installer ou menu ⋮ → Installer l'application. Sur iPhone/iPad (Safari), bouton Partager → Sur l'écran d'accueil. Elle fonctionne ensuite sans Internet.
  • Clic droit ou Suppr pour effacer, Ctrl+Z pour annuler. Ton schéma est gardé dans ce navigateur.
